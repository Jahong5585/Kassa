КАССА МИНИМАРКЕТА
Версия 0.5.8 · Пилот · Windows x64

БЫСТРЫЙ ЗАПУСК

1. Распакуйте весь ZIP в отдельную папку.
2. Запустите KassaSetup.exe и откройте Kassa Minimarket из меню «Пуск».
   Для переносного запуска откройте portable\KasaDesktop.exe.
   Нужны .NET Framework 4.8 и Microsoft Edge WebView2 Runtime.
   https://developer.microsoft.com/microsoft-edge/webview2/
3. В окне «Продажа» нажмите «Открыть смену» и задайте размен,
   например 50 000 сум.
4. Введите 4780011001002 и нажмите Enter. Это учебный товар
   «Хлеб пшеничный» по цене 5 500 сум. F3 возвращает фокус в поиск.
   Для поиска по названию можно ввести «яблоки» и нажать Enter.
5. Нажмите F2, введите 10 000 сум и подтвердите оплату.
   Сдача составит 4 500 сум. Чек имеет отметку «Тестовый • нефискальный».
6. «Чеки» открывает журнал и позволяет повторно напечатать тот же чек.
   «Смена» показывает остаток наличных и позволяет закрыть смену
   по фактическому пересчёту.

Для подключения 0.5.8 к стенду нужен обновлённый сервер с миграцией 028.
Администратор включает акцию 2+1 в карточке штучного товара.
Для уценки откройте «Приёмка и склад → Остатки → Уценка и код партии».
Укажите цену и причину. Скопируйте код LOT для внутренней этикетки.
Пустая цена снимает уценку. Назначенный код сохраняется.

На стенде «Отложить чек» сохраняет корзину в открытой смене. Откройте
«Отложенные чеки», чтобы восстановить её или отменить с причиной.
При изменении цены проверьте новый итог перед подтверждением.

НОВОЕ В ЭТАПЕ 2

• Чеки → Возврат. Выберите позицию, количество, причину и направление
  товара. Деньги выдаются после сообщения «Возврат сохранён».
  Для проверки учебного лимита продайте две упаковки яиц (штрихкод
  4780011001003). Возврат двух упаковок на сумму 36 000 сум запросит
  учебное подтверждение, затем нажмите «Завершить возврат».
• Смена → Внести наличные / Изъять наличные. Введите сумму и причину.
  Запись появится в журнале смены.
• Сроки → Просрочено → Снято с полки. В новом учебном каталоге есть
  просроченная партия кефира. Отметка создаёт задачу администратору
  и сохраняет учётный остаток до её обработки.
• 4780011001001 — молоко из двух партий. Сверьте дату и выберите партию.
• Настройки → «Потерять ответ на следующую продажу» включает учебный
  тайм-аут. Касса найдёт чек по исходному ID.

ПРИЁМКА И СКЛАД

1. В разделе «Приёмка» выберите «Приёмщик» → «Новая накладная».
   Укажите поставщика, дату и номер. Можно выбрать учебный заказ.
2. Добавьте хлеб по штрихкоду 4780011001002 дважды, чтобы создать
   две партии. Введите суммарно 12 штук и будущие сроки годности.
3. Сохраните черновик, приложите учебный образец и передайте
   накладную на проверку.
4. Выберите «Администратор», откройте накладную, введите закупочную
   цену по каждой партии, сохраните стоимость и проведите документ.
5. В разделе «Остатки» проверьте обе партии. Из строки партии можно
   начать пересчёт, оформить карантин или списание с указанием причины.
   Задачи кассира обрабатываются в разделе «Снятие с полки».

На стенде для приёмки и склада в разделе «Приёмка» подключите нужную
роль через «Подключить стенд». Профиль KasaPilot.json включает вход
через системный браузер. Настройку профиля см. в PILOT.md.
Вложения выбираются через окно Windows. Сервер принимает до трёх
файлов PDF, JPEG или PNG до 2 МиБ каждый. Проведение доступно после
проверки файлов. Скачивание оригинала доступно администратору.

УПРАВЛЕНИЕ МАГАЗИНОМ

1. Откройте «Приёмка» → «Администратор» → «Управление».
2. В каталоге добавьте товар, установите цену или проверьте CSV перед
   применением. В «Предложениях» доступны заявки приёмщиков.
3. В «Поставщиках» добавьте карточку и закупочную цену упаковки.
4. Создайте заказ вручную или рассчитайте закупку из предложения
   поставщика. Утвердите текущую версию заказа. Отметьте фактическую
   отправку, указав номер или ссылку. Заказ появится у приёмщика.
5. В «Отчётах и аудите» выберите период, сформируйте отчёт и, где
   доступно, сохраните CSV.

ЯЗЫК И УСТРОЙСТВА

В «Настройках» можно переключить язык на O‘zbekcha, проверить ввод
сканера штрихкодов и весов с клавиатурным выводом, а также просмотреть
список принтеров Windows. Печать выполняется через системное окно.

ОБ УЧЕБНОМ СТЕНДЕ

По умолчанию программа работает локально без подключения к серверу.
Чтобы проверить API, откройте «Настройки → Подключить учебный стенд».
С настроенным профилем KasaPilot.json введите ключ кассы и войдите
через системный браузер. Без профиля для тестового стенда доступен
ручной ввод HTTPS-адреса, UUID кассы, ключа и короткоживущего JWT.
Ключ и токен хранятся в памяти. При необходимости обновите сеанс.

Сверхлимитный возврат на стенде подтверждает администратор. В отдельном
сеансе войдите под учётной записью администратора с требуемым MFA.
После подтверждения нажмите «Завершить возврат». Касса использует
исходный ID операции.

Если результат операции неясен, используйте «Проверить статус» или
«Подтвердить той же заявкой» для снятия с полки. После перезапуска
подключите тот же сервер, кассу и учётную запись. Данные первого этапа
читаются из того же профиля Windows.

Сборка пилота поставляется без подписи издателя. В архиве есть
исходники, протокол PILOT.md и результаты испытаний в RELEASE.md.

В «Настройки → Проверка оборудования» нажмите «Найти USB-принтеры и драйверы».
Подключение принтера, скачивание и настройка своего сервера описаны в PRINTER_DRIVERS.md.

Для продажи товара без штрихкода найдите его по названию и нажмите «Закрепить».
На экране продажи появится быстрая кнопка. Одно нажатие добавляет одну штуку.
