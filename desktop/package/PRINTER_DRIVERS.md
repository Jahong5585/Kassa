# Чековые принтеры в «Кассе» 0.5.6

## Поиск и установка на кассе

1. Завершите расчёт, затем подключите чековый принтер по USB и включите питание. Откройте «Настройки → Проверка оборудования → Найти USB-принтеры и драйверы».
2. «Касса» читает подключённые устройства Windows. Она показывает интерфейсы USB-печати и USB-устройства, в имени которых есть точная модель из каталога. Код 28 означает, что Windows сообщает об отсутствии драйвера. Когда имя общее, сверьте модель по наклейке и выберите её вручную. Список установленных очередей открывается отдельно кнопкой «Проверить принтеры».
3. Для Epson TM-T20III и перечисленных моделей Rongta кнопка скачивает официальный пакет на Windows x64. Для Epson сначала доступны условия лицензии и подтверждение скачивания. Для Xprinter и Bixolon откройте страницу производителя, выберите Windows и следуйте инструкции на странице. В установщике общего драйвера выберите точную модель и USB-порт.
4. При запуске установщика подтвердите действие в программе и в Windows. После завершения нажмите «Проверить принтеры». Выберите нужный принтер и распечатайте учебный чек. Если очередь отсутствует, завершите настройку USB-порта в мастере производителя. Подключение модели с фирменным USB-интерфейсом, которую Windows показывает как неизвестное устройство, проверяйте через выбор модели вручную.

## Размещение разрешённых пакетов на своём сервере

1. Получите исходный автономный EXE у производителя. Сверьте поддерживаемые модель и Windows x64. Убедитесь, что условия производителя допускают выбранный способ размещения и выдачи файла. Для пакета Epson штатный путь ведёт напрямую к производителю. [Лицензия Epson](https://epson.com/SoftwareLicenseAgreement)
2. Проверьте издателя и статус `Valid` командой PowerShell `Get-AuthenticodeSignature .\driver.exe`. Получите SHA-256 командой `Get-FileHash .\driver.exe -Algorithm SHA256`. Зафиксируйте контрольную сумму из проверенного экземпляра до загрузки на сервер.
3. Положите файл в закрытую на запись статическую HTTPS-папку, например `https://pos.example.org/printer-drivers/`. Настройте выдачу файла по точному имени без перенаправления, с сертификатом, которому доверяет Windows. Для драйверов кассовый API и база PostgreSQL отдельного обновления не требуют.
4. Скопируйте `PrinterDrivers.example.json` как `PrinterDrivers.json` рядом с KasaDesktop.exe. Укажите HTTPS-папку в `repository`. В `packages` внесите по одной записи на модель с ключами `model`, `file` и `sha256`. Пример идентификатора модели `xprinter-xp-58iih`. Полный список ключей находится в `source/PrinterDriverCatalog.cs`. Если драйвер общий, укажите одно имя файла и одну контрольную сумму в записях каждой поддерживаемой модели.
5. Ограничьте права записи к конфигурации и установленным файлам кассы. Обновление пакета делайте с новым именем файла и проверенной SHA-256. При следующей проверке USB кнопка покажет «Установить драйвер с сервера» только для заполненной модели.

Ограничения пакета с сервера — до 20 записей, автономный EXE до 64 МиБ, один каталог HTTPS, имя файла без пути. Касса сверяет локально утверждённый хеш и подпись Authenticode перед запуском. Само размещение файлов выполняет администратор сервера. Пустой шаблон использует официальные загрузки и страницы производителей. Установку и печать на реальном Windows-ПК проверьте до применения на рабочей кассе.
